# Модуль search: поиск вещей

Ссылки на поиск по магазинам (без ИИ) и поиск конкретных моделей с веб-поиском OpenRouter (только Pro).

| Файл                        | Что внутри                                                                             |
| --------------------------- | -------------------------------------------------------------------------------------- |
| `index.js`                  | манифест: вкладка «Поиск», `requires: profile, capsule`, подписка на `capsule:rebuilt` |
| `model.js`                  | слайс `search`, `remember`, `clearCache`                                               |
| `schema.js`                 | `normalizeSearch`                                                                      |
| `shops.js`                  | шаблоны ссылок магазинов. Партнёрские метки добавлять сюда                             |
| `view.js`                   | экран. `#search/<id покупки>` открывает вещь из капсулы                                |
| `server/modules/search.mjs` | задача `search` (Pro, веб-поиск), проверка ссылок по источникам                        |

**Данные** (`mod:search`, версия 1): `{ cache: { [запрос]: { results, verified, at } }, last }`.

**Зависит от:** profile (палитра, бюджет, город), capsule (список покупок). **От него зависят:** никто.

**Тесты:** `test/normalize.test.mjs` (результаты), `test/api.test.mjs` (Pro, проверка ссылок).
