# Модуль logs: журнал задач для разработчика

Вкладка «Логи», видна только в режиме разработчика (код `ADMIN_CODE`, в `npm run dev` по умолчанию `dev`). Показывает последние 40 задач из этого браузера: вход задачи (фото заменены размером), промпт system и user, каждый запрос к модели (протокол, параметры, статус, время до первого байта и первого токена), повторы, отброшенные параметры, смену протокола и effort, разбор JSON, сырой ответ модели, токены, цену, код запроса. Запись можно скопировать или скачать весь журнал JSON-файлом.

Данные пишет ядро (`core/devlog.js`) из событий `debug`, которые сервер шлёт в потоке ответа только разработчику (`server/log.mjs`). Ссылка `#logs/<код запроса>` из сообщения об ошибке открывает нужную запись.

| Файл       | Что внутри                                                  |
| ---------- | ----------------------------------------------------------- |
| `index.js` | манифест: вкладка «Логи», видимость, перерисовка по событию |
| `view.js`  | экран журнала                                               |

**Зависит от:** только ядра. **От него зависят:** никто. Удаляется без последствий: журнал продолжит писаться ядром, но смотреть его будет негде.
