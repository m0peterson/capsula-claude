# Модуль settings: настройки

Подписка (код Pro, режим разработчика), подмена моделей для разработчика по слотам `vision`, `detect`, `text`, копия данных, удаление данных. Своих данных нет: настройки в localStorage (`core/settings.js`), данные модулей в `core/store.js`.

| Файл       | Что внутри                    |
| ---------- | ----------------------------- |
| `index.js` | манифест: вкладка «Настройки» |
| `view.js`  | экран                         |

**Зависит от:** только ядра. **От него зависят:** никто. Ссылка `#settings/pro` сразу открывает окно оплаты.
