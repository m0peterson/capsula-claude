# Capsula: ИИ-стилист

Веб-приложение без сборки: статика в `public/` и API `/api/*`, которое само собирает промпты, вызывает модель и решает, какая часть результата бесплатна.

Что умеет:

1. **Профиль**: анализ фото (цветотип из 12 сезонов и соседний сезон, пропорции, фигура, рост из анкеты) и подбор стилей и силуэтов с описанием.
2. **Гардероб**: загрузка вещей фото, распознавание (категория, цвет, ткань, сезон) пачками по 6 фото, три пачки параллельно, ручная правка.
3. **Образы**: готовые луки только из вашего гардероба с учётом пожеланий по стилю.
4. **Капсула**: палитра, что оставить, что докупить (с приоритетом, ценой и парами), образы капсулы. Работает и с гардеробом, и с нуля.
5. **Поиск**: ссылки на Lamoda, Wildberries, Ozon, Яндекс Маркет, Google Покупки, ASOS, Zara, Pinterest и поиск конкретных моделей через ИИ с веб-поиском (OpenRouter).

## Как устроено

Браузер отправляет на сервер только данные: фото, анкету, гардероб, пожелания. Промпты (`lib/prompts.mjs`), выбор модели, проверка входа и граница бесплатного плана живут на сервере (`lib/tasks.mjs`, `lib/api.mjs`). Ключи провайдеров в браузер не попадают, а сервер не пересылает провайдеру произвольные запросы: раньше `/api/llm` с серверным ключом мог использовать как бесплатный API любой, кто нашёл адрес.

| Маршрут              | Что делает                                                                                                                |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `GET /api/config`    | готов ли сервер, включён ли платный доступ, цена, ссылка на оплату, доступен ли веб-поиск                                 |
| `POST /api/task`     | задача `analysis`, `wardrobe`, `looks`, `capsule` или `search`; ответ потоком SSE: `progress`, затем `result` или `error` |
| `POST /api/activate` | код Pro → подписанный токен; код разработчика → режим разработчика                                                        |
| `POST /api/unlock`   | с Pro-токеном вскрывает конверты с полными результатами                                                                   |

Данные пользователя (фото, гардероб, результаты) хранятся только в IndexedDB браузера. Сервер ничего не сохраняет: фото уходят провайдеру модели на время запроса. На OpenRouter запросы идут только к провайдерам без хранения данных и без обучения на них (`provider.data_collection = deny`).

## Платный доступ

Включается переменной `PRO_SECRET`. Без неё всё открыто (режим пилота).

- **Бесплатно**: цветотип, соседний сезон, 4 лучших цвета, тип фигуры, один стиль; распознавание гардероба; первые 2 образа; концепция, палитра и 3 самые важные покупки капсулы; ссылки на магазины.
- **Pro**: остальная палитра, нейтрали, цвета, которых избегать, металлы, пропорции, силуэты по зонам, ткани, итог, все образы, капсула целиком, поиск с ИИ.
- Если фигуру по фото определить не удалось, этот блок не закрывается: продавать «не определено» нельзя.

Полный результат генерируется сразу, бесплатному пользователю приходит урезанная версия и **конверт**: полный результат, зашифрованный AES-GCM ключом из `PRO_SECRET`. После покупки сервер вскрывает конверт, и человек видит ровно то, что ему показали частично, без повторной генерации и без базы данных.

**Pro-токен** подписан HMAC и содержит срок действия. Сейчас его выдают в обмен на код из `PRO_CODES`. Это ручной режим для проверки спроса: продавать коды через ссылку `PAY_URL` (Boosty, Tribute, YooMoney и т. п.). Для настоящей оплаты нужен вебхук платёжки, который выдаёт токен, и хранилище, чтобы код нельзя было передать другу. Коды из `PRO_CODES` многоразовые.

Лимит частоты (20 задач за 10 минут с одного IP на бесплатном плане, 120 на Pro, 10 попыток ввода кода) хранится в памяти экземпляра функции. На serverless это защита от скриптов, а не квота.

## Переменные окружения

| Переменная                     | Зачем                                                                                                                                       |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `OPENROUTER_API_KEY`           | ключ OpenRouter (основной провайдер)                                                                                                        |
| `OPENCODE_GO_API_KEY`          | ключ OpenCode Go, только для тестов (см. ниже)                                                                                              |
| `LLM_PROVIDER`                 | `openrouter` или `opencode-go`; по умолчанию тот, чей ключ задан                                                                            |
| `MODEL_VISION`, `MODEL_TEXT`   | модели для фото и для текста; по умолчанию `deepseek/deepseek-v4.1-flash`                                                                   |
| `MODEL_FALLBACK`               | запасная модель OpenRouter, по умолчанию `openai/gpt-6-luna`; пустая строка отключает                                                       |
| `EFFORT_VISION`, `EFFORT_TEXT` | effort рассуждений; по умолчанию `low` для фото и `none` для образов, капсулы и поиска                                                      |
| `OPENROUTER_SORT`              | как OpenRouter выбирает провайдера модели: `throughput` (по умолчанию), `latency` или `price`                                               |
| `MAX_TOKENS`                   | потолок ответа вместе с рассуждениями, по умолчанию 24000; 0 значит не передавать                                                           |
| `PRO_SECRET`                   | включает платный доступ; ключ подписи токенов и шифрования конвертов. Не меняйте без нужды: старые токены и конверты перестанут открываться |
| `PRO_CODES`                    | коды Pro через запятую, `КОД` или `КОД:дней` (по умолчанию 30 дней)                                                                         |
| `PRO_PRICE`                    | цена для окна оплаты, например `490 ₽ в месяц`                                                                                              |
| `PAY_URL`                      | https-ссылка на оплату                                                                                                                      |
| `ADMIN_CODE`                   | код разработчика: всё открыто, в настройках можно подменить провайдера, модель и effort, в ошибках виден сырой ответ модели                 |

## Модели

Замеры на одних и тех же фото (октябрь 2026, OpenRouter, effort `low`):

| Модель                            | Анализ фото           | 8 вещей одним запросом | Заметки                                                         |
| --------------------------------- | --------------------- | ---------------------- | --------------------------------------------------------------- |
| `deepseek/deepseek-v4.1-flash`    | 12-21 с, $0.003-0.004 | 17 с, 8 из 8, $0.0056  | по умолчанию                                                    |
| `openai/gpt-6-luna`               | 19-21 с, $0.001       | 17 с, 8 из 8, $0.0009  | дешевле и чуть стабильнее по цветотипу, запасная модель         |
| `z-ai/glm-5.3-flash`              | 14-17 с, $0.001       | разобрал 1 фото из 8   | для гардероба не годится                                        |
| `google/gemini-4-argon`           | 34 с, $0.029          |                        | в 10 раз дороже без заметной разницы в качестве                 |
| `meta/muse-spark-1.3-contributor` | 29 с, $0.0006         |                        | провайдер обучается на запросах, для фото людей не использовать |

Весь путь пользователя (анализ, 8 вещей, образы, капсула, поиск) стоит около $0.02.

Цветотип по фото у пограничных внешностей плавает даже при `temperature: 0`: один и тот же снимок давал то «Тёмную осень», то «Тёмную зиму». Поэтому модель выбирает сезон строго из 12 названий и называет соседний сезон. При повторе человек видит ту же пару.

**OpenCode Go** рассчитан на трафик кодинг-агентов: без заголовка `x-opencode-session` запросы отклоняются, трафик мониторится на злоупотребления. Это подписка с месячным лимитом, а не бесплатный доступ (deepseek-v4.1-flash там стоит $0.15-0.30 / $1.20 за 1M токенов из лимита). Бесплатные `-free` модели работают только из самого OpenCode. Gemini 4 Argon и GPT 6 Luna там отвечают по другим протоколам и через этот клиент не работают. Для продакшена используйте OpenRouter.

## Запуск локально

```bash
OPENROUTER_API_KEY=sk-or-... npm run dev   # http://localhost:8888
PRO_SECRET=dev PRO_CODES=TEST ADMIN_CODE=me OPENROUTER_API_KEY=sk-or-... npm run dev   # с платным доступом
npm test
```

Нужен Node 20+. Зависимостей нет. Dev-сервер слушает только `127.0.0.1` и принимает `/api/*` только с Host `localhost`/`127.0.0.1`, потому что использует ключи из окружения.

## Деплой

### Cloudflare Workers

Ожидание ответа модели не считается в лимит CPU, поэтому долгие ответы не обрываются. Технически это лучшая площадка для этого кода, но с июня 2025 российские провайдеры замедляют соединения с Cloudflare. Если аудитория в России, проверьте адрес с российского интернета без VPN (подробнее в `docs/product/README.md`, раздел 9).

```bash
npx wrangler deploy
npx wrangler secret put OPENROUTER_API_KEY   # и остальные переменные
```

Настройки в `wrangler.jsonc`: статика из `public/`, `/api/*` идёт в `worker/index.mjs`.

### Netlify

Netlify обрывает функцию примерно через 30 секунд, и стриминг этот срок не продлевает (замерено в октябре 2026 на бесплатном плане: обрывы на 30.6 и 31.1 с). Обычно задачи укладываются в 10-20 секунд, но редкий медленный ответ провайдера обрывается. Клиент в этом случае один раз повторяет задачу сам.

1. Репозиторий в Netlify: _Add new site → Import from Git_. Настройки подтянутся из `netlify.toml` (publish `public`, функции `netlify/functions`).
2. _Site configuration → Environment variables_: переменные из таблицы выше.
3. Либо через CLI: `npx netlify deploy --prod`.

### Cloudflare Pages

Тот же код, обёртка в `functions/api/[[path]].js`. _Workers & Pages → Create → Pages → Connect to Git_, build command пустой, output directory `public`, переменные в _Settings → Variables and secrets_.

Заголовки безопасности (CSP, запрет фреймов и т. п.) лежат в `public/_headers`, его читают и Netlify, и Cloudflare.

## Структура

```
public/             статика и клиентские модули (без сборки)
  js/api.js         клиент API: задачи потоком SSE, активация кода, вскрытие конвертов
  js/pro.js         окно Pro, заглушки на месте скрытого
  js/views/         экраны: profile, wardrobe, looks, capsule, search, settings
  js/normalize.js   приведение ответов модели к форме интерфейса (общий для клиента и сервера)
  js/util.js        разбор JSON из ответа модели, безопасные URL и картинки (общий)
lib/api.mjs         HTTP API (общий для Netlify, Cloudflare и dev-сервера)
lib/tasks.mjs       задачи: проверка входа, промпт, нормализация, бесплатная часть
lib/prompts.mjs     промпты стилиста и JSON-схемы ответов
lib/llm.mjs         клиент к OpenAI-совместимым API: стриминг, effort, повторы, разбор JSON
lib/paywall.mjs     Pro-токены (HMAC) и конверты (AES-GCM) на Web Crypto
worker/             Cloudflare Worker
netlify/functions/  обёртка для Netlify
functions/api/      обёртка для Cloudflare Pages
test/               тесты API, клиента модели, разбора JSON, нормализации, dev-сервера
docs/product/       продуктовый разбор и план монетизации
```

## Ограничения

- Качество анализа зависит от света и модели. Рост по фото не определяется надёжно, укажите его в анкете.
- Ссылки от ИИ-поиска проверяются по списку источников веб-поиска, если провайдер его отдаёт. Если нет, они помечаются как непроверенные.
- Нет аккаунтов и синхронизации между устройствами: Pro-токен живёт в браузере, где его активировали.
