## 1. Локально за 5 минут

Нужен Node 20 или новее. Зависимостей нет, `npm install` не нужен.

```bash
git clone https://github.com/m0peterson/capsula-claude.git
cd capsula-claude
git checkout claude/loving-dijkstra-libwun
```

Создайте в корне файл `.dev.vars` (он в `.gitignore`, в репозиторий не попадёт):

```
OPENROUTER_API_KEY=sk-or-v1-...
OPENCODE_GO_API_KEY=oc_sk_...
```

Достаточно одного ключа. Если есть оба, основным будет OpenRouter.

```bash
npm run dev
```

В терминале появится:

```
http://localhost:8888
ключи: OPENROUTER_API_KEY, OPENCODE_GO_API_KEY; провайдер: по ключу
логи: этот терминал (LOG_LEVEL=debug), файл .logs/api.jsonl
вкладка «Логи»: Настройки → Ввести код → dev
```

Откройте http://localhost:8888, зайдите в «Настройки» → «Ввести код» → `dev` → «Активировать». Появится вкладка «Логи», все результаты откроются без Pro.

Проверить платный доступ локально:

```bash
PRO_SECRET=test PRO_CODES=TEST PRO_PRICE="490 ₽ в месяц" npm run dev
```

Тогда без кода видна бесплатная часть результатов, код `TEST` открывает Pro на 30 дней.

Тесты: `npm test` (161 тест, около 2 секунд, в сеть не ходят).

## 2. Деплой на Cloudflare Workers

### Один раз: доступ

Вариант А, на своём компьютере: `npx wrangler login`, откроется браузер.

Вариант Б, токен (для серверов, CI, облачных сессий):

1. Панель Cloudflare → иконка профиля → My Profile → API Tokens → Create Token → шаблон «Edit Cloudflare Workers».
2. ID аккаунта: Workers & Pages, справа на странице обзора.
3. В терминале:

```bash
export CLOUDFLARE_API_TOKEN=...
export CLOUDFLARE_ACCOUNT_ID=...
```

### Выкатить

```bash
npx wrangler deploy --name capsula-claude
```

Займёт 10-20 секунд. В конце будет адрес и `Current Version ID`. Без `--name` создастся отдельный воркер `capsula`: так задуман продакшен, тестовый воркер не тронется.

Что выкатывается: статика из `public/`, а `/api/*` обрабатывает `worker/index.mjs` (настройки в `wrangler.jsonc`). Файлы `.dev.vars` и `.logs/` не уходят.

### Секреты и переменные

```bash
npx wrangler secret put OPENROUTER_API_KEY --name capsula-claude   # спросит значение
npx wrangler secret list --name capsula-claude                     # какие заданы (без значений)
npx wrangler secret delete MODEL_DETECT --name capsula-claude      # убрать
```

Каждый `secret put` сразу создаёт новую версию воркера, передеплоить не нужно. Все настройки (модели, уровень логов, Pro) задаются так же, как секреты: в коде они читаются одинаково.

Минимум для работы: `OPENROUTER_API_KEY`. Для платного доступа ещё `PRO_SECRET` (любая длинная случайная строка, после запуска не менять: старые токены и конверты перестанут открываться), `PRO_CODES`, `PRO_PRICE`, по желанию `PAY_URL`. Для режима разработчика `ADMIN_CODE`.

### Проверить после деплоя

```bash
curl https://capsula-claude.yaroslav-galevich.workers.dev/api/config
```

Должно быть `"ready":true`. Если `false`, на сервере нет ключа выбранного провайдера.

### Откатить

```bash
npx wrangler deployments list --name capsula-claude   # история, id версий
npx wrangler rollback <version-id> --name capsula-claude
```

## 3. Режим разработчика

Включается кодом из `ADMIN_CODE`: «Настройки» → «Ввести код». Если код на воркере забыт, задайте новый: `npx wrangler secret put ADMIN_CODE --name capsula-claude`, затем в приложении «Выключить режим разработчика» и введите новый.

Что даёт:

- все результаты открыты без Pro;
- вкладка «Логи» (раздел 4);
- в «Настройках» подмена провайдера, модели и effort отдельно для трёх слотов: фото (анализ и распознавание вещей по одной), вещи из фото образов (рамки), текст (образы, капсула, поиск). Подмена действует только для запросов из этого браузера, остальные пользователи её не видят. Пустое поле значит «как на сервере», серверное значение показано серым;
- в ошибках виден сырой ответ модели.

Как сравнить две модели: включите режим разработчика, запустите задачу, поменяйте модель в «Настройках», запустите ту же задачу ещё раз. На вкладке «Логи» у двух записей будут время, токены, цена и ответы рядом.

Защита: 10 неверных кодов с одного IP за 10 минут, и код с этого IP не принимается даже верный, пока окно не пройдёт.

## 4. Логи: где смотреть

| Где                    | Когда смотреть                                         | Как открыть                                                                       |
| ---------------------- | ------------------------------------------------------ | --------------------------------------------------------------------------------- |
| Вкладка «Логи»         | всегда первым делом: там промпт и ответ модели целиком | режим разработчика → вкладка «Логи»                                               |
| Терминал `npm run dev` | локальная разработка, видно всё в реальном времени     | просто смотреть в терминал                                                        |
| `npm run logs`         | разобрать прошлую задачу локально                      | см. ниже                                                                          |
| `npm run logs:worker`  | что происходит на воркере прямо сейчас                 | нужен доступ из раздела 2                                                         |
| Панель Cloudflare      | что было на воркере за последние дни                   | Workers & Pages → `capsula-claude` → вкладка Observability (в старой панели Logs) |
| OpenRouter             | спор о цене или ответе конкретной генерации            | openrouter.ai → Activity, поиск по `id=gen-...` из лога                           |

### Код запроса

У каждой задачи есть код из 10 символов, например `f1a400d831`. Его видно под текстом ошибки в приложении (у всех пользователей), в заголовке ответа `x-request-id` и в каждой строке лога. Если пользователь прислал скриншот ошибки, по коду находится вся цепочка:

```bash
npm run logs -- f1a400d831                                      # локально
npx wrangler tail capsula-claude --format pretty --search f1a400d831   # на воркере, только новые события
```

В режиме разработчика под ошибкой есть ссылка «открыть лог»: она ведёт сразу на запись во вкладке «Логи».

### `npm run logs`

```bash
npm run logs                 # последние 5 задач
npm run logs -- 20           # последние 20
npm run logs -- --errors     # только упавшие
npm run logs -- --full       # с промптами и ответами модели
npm run logs -- -f           # следить за новыми событиями
```

Файл `.logs/api.jsonl` растёт без ограничений, удаляйте его, когда мешает.

### Вкладка «Логи»

Каждая запись это одна задача. В заголовке: статус, задача, время, длительность, модель, токены, цена, код запроса. Внутри лента событий и раскрывающиеся блоки: промпт system и user, ответ модели на каждую попытку, текст ошибки провайдера, параметры запросов, вход задачи (фото заменены размером). Кнопки: «Скопировать запись», «Скопировать всё», «Скачать JSON», «Только ошибки», «Очистить». Журнал хранит 40 последних задач в этом браузере.

Чтобы попросить помощи с отладкой, нажмите «Скопировать запись» и вставьте её в чат: там есть всё, кроме фото.

### Как читать ленту

Пример настоящей записи (анализ фото через OpenRouter):

```
+22 мс   openrouter · meta/muse-spark-1.3-contributor (запасная openai/gpt-6-luna) · effort low · data_collection allow · фото: jpeg 139 КБ
+23 мс   → chat #1 meta/muse-spark-1.3-contributor · 190 КБ · reasoning={"effort":"low"} temperature=0 max_tokens=24000 response_format=...
+621 мс  ← #1 HTTP 200 за 605 мс
+26.1 с  ✓ модель ответила за 26.1 с (первый токен 3.4 с) · 4466 зн. · finish stop · 1897 → 2305 ток., рассуждения 762, $0.00064 [Meta]
+26.1 с  JSON разобран
+26.1 с  ■ готово за 26.1 с
```

| Значок или поле           | Что значит                                                                                                          |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| первая строка             | что выбрал сервер: провайдер, модель, запасная модель, effort, политика данных, размеры фото, длина промпта         |
| `→ chat` / `→ responses`  | запрос ушёл, протокол, номер попытки, размер, параметры                                                             |
| `← HTTP 200 за 605 мс`    | провайдер принял запрос. Если это число большое, очередь у провайдера (у OpenCode Go 6-12 с это норма)              |
| `первый токен 3.4 с`      | когда модель начала отвечать. Всё после этого это генерация: длинный ответ идёт долго                               |
| `рассуждения 762`         | токены на размышления. Если их тысячи, проверьте effort                                                             |
| `ответила ...`            | ответила не та модель, что просили: сработала запасная                                                              |
| `[Meta]`                  | какой провайдер обслужил запрос в OpenRouter                                                                        |
| `↻`                       | повтор: временная ошибка провайдера (429, 5xx) или обрыв сети, делается один раз                                    |
| `⚙`                       | сервер поменял параметр и повторил: модель не приняла effort, JSON-режим, лимит токенов или протокол. Это нормально |
| `✗`                       | ошибка провайдера, полный текст в блоке «Ошибка провайдера»                                                         |
| `JSON разобран (починен)` | модель прислала кривой JSON, сервер починил сам                                                                     |
| `[json-retry]`            | JSON не разобрался, сервер попросил модель прислать ответ заново                                                    |

### Уровни логов на сервере

Переменная `LOG_LEVEL` управляет тем, что пишется в консоль сервера (терминал, `wrangler tail`, панель Cloudflare):

| Уровень         | Что пишется                                           | Когда ставить                                  |
| --------------- | ----------------------------------------------------- | ---------------------------------------------- |
| `info` (умолч.) | строка на задачу: модель, время, токены, цена, ошибка | продакшен                                      |
| `debug`         | ещё каждый запрос к модели, повторы, статусы          | тестовый воркер (стоит сейчас), разбор проблем |
| `trace`         | ещё промпты с анкетой пользователя и ответы модели    | только локально или на время разбора           |

Запросы с кодом разработчика пишутся как `debug` при любом уровне. `LOG_FORMAT=pretty` делает строки читаемыми в `wrangler tail`, но панель Cloudflare лучше ищет по JSON, поэтому на воркере оставьте `json`.

Фото не пишутся никуда и никогда, только их размер.

## 5. Частые ошибки

| Что видно                                                 | Причина                                                                                     | Что делать                                                                                                                        |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Баннер «На сервере не настроен ключ провайдера ИИ»        | нет ключа выбранного провайдера                                                             | `npx wrangler secret put OPENROUTER_API_KEY --name capsula-claude`                                                                |
| Баннер «Сервер приложения недоступен»                     | `/api/config` не ответил: открыта статика без API или упал воркер                           | `curl .../api/config`, затем `npm run logs:worker`                                                                                |
| `No endpoints found matching your data policy`            | модель `-contributor` с политикой `deny`                                                    | убрать `OPENROUTER_DATA_COLLECTION=deny`; если не задан, проверить openrouter.ai/settings/privacy                                 |
| `... is not a valid model ID`                             | опечатка в имени модели                                                                     | имена: openrouter.ai/models; у OpenCode Go имена без префикса (`muse-spark-1.3-contributor`)                                      |
| `Model does not support this protocol` после `⚙ протокол` | модели OpenCode Go нужен третий протокол (Gemini Argon, Claude)                             | эти модели через OpenCode Go пока не работают, берите их через OpenRouter                                                         |
| `Веб-поиск работает только через OpenRouter`              | в настройках разработчика выбран OpenCode Go                                                | переключить провайдера на OpenRouter                                                                                              |
| `Ответ модели обрезан: исчерпан лимит токенов`            | ответ вместе с рассуждениями длиннее `MAX_TOKENS` (24000)                                   | снизить effort или поднять `MAX_TOKENS`                                                                                           |
| `не удалось разобрать как JSON`                           | модель ответила не JSON                                                                     | вкладка «Логи» → «Ответ модели», там видно, что именно пришло                                                                     |
| `Соединение ... оборвалось`                               | обрыв сети или таймаут площадки (на Netlify через 30 с)                                     | браузер повторяет сам один раз; если часто, смотреть время в логах                                                                |
| `Слишком много запросов`                                  | лимит приложения: 20 задач за 10 минут с IP на бесплатном плане, 120 на Pro                 | подождать; в режиме разработчика лимит Pro                                                                                        |
| HTTP 402 от OpenRouter                                    | закончились деньги на счёте или лимит ключа                                                 | openrouter.ai → Credits или Keys                                                                                                  |
| Ссылки поиска с пометкой «не проверены»                   | провайдер не вернул список источников                                                       | в строке `✓ модель` нет «источников N»: ссылки могли быть выдуманы, проверьте движок поиска (`exa` в `server/modules/search.mjs`) |
| Всё медленно                                              | смотреть, где время: `← HTTP` (очередь), `первый токен` (думает), остальное (длинный ответ) | рассуждения в тысячах токенов: снизить effort; долгий `← HTTP` у OpenCode Go: переключиться на OpenRouter                         |

## 6. Модели: как поменять и что рекомендую

Сейчас Muse Spark 1.3 Contributor стоит везде. У этого два минуса, оба замерены 23 октября:

1. **Рамки вещей на сложных фото неточные** (перчатки обведены по всему телу, очки и юбка мимо). Gemini 3.8 Flash на тех же фото точен, 12 с и $0.010 за импорт.
2. **Meta обучается на запросах**, то есть на фото пользователей. Подробности в README и в продуктовом разборе, раздел 14.

Рекомендуемая настройка: Muse Spark на тексте, на фото модели без обучения.

```bash
npx wrangler secret put MODEL_DETECT --name capsula-claude   # google/gemini-3.8-flash
npx wrangler secret put MODEL_VISION --name capsula-claude   # deepseek/deepseek-v4.1-flash
```

Для этих моделей политика данных автоматически станет `deny`. Вернуть всё как было: `npx wrangler secret delete MODEL_DETECT --name capsula-claude` и то же для `MODEL_VISION`.

Другие рычаги:

| Переменная                                      | Пример              | Что делает                                                                                  |
| ----------------------------------------------- | ------------------- | ------------------------------------------------------------------------------------------- |
| `LLM_PROVIDER`                                  | `opencode-go`       | основной провайдер. У OpenCode Go нет веб-поиска и он медленнее на старте                   |
| `MODEL_VISION`, `MODEL_DETECT`, `MODEL_TEXT`    | имя модели          | модель слота основного провайдера                                                           |
| `EFFORT_VISION`, `EFFORT_DETECT`, `EFFORT_TEXT` | `minimal`           | глубина рассуждений: `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`             |
| `MODEL_FALLBACK`                                | `openai/gpt-6-luna` | запасная модель OpenRouter для фото и текста, срабатывает, только если основная недоступна  |
| `OPENROUTER_DATA_COLLECTION`                    | `deny`              | запретить провайдеров, которые учатся на запросах (модели `-contributor` тогда не работают) |
| `MAX_TOKENS`                                    | `24000`             | потолок ответа вместе с рассуждениями                                                       |

Перед тем как менять модель на воркере, проверьте её в режиме разработчика через подмену в «Настройках»: это ничего не ломает остальным.

## 9. Старый Pages-проект: закрыть

`capsula-claude-pages.pages.dev` работает на коде из старой сессии: пересылает любой запрос в OpenRouter с вашим ключом, кода доступа нет. 23 октября на запрос к `/api/llm` ответил сам OpenRouter. Убыток ограничен лимитом ключа, но любой, кто найдёт адрес, может его выжечь.

Проще всего удалить проект:

```bash
npx wrangler pages project delete capsula-claude-pages
```

Или в панели: Workers & Pages → `capsula-claude-pages` → Settings → Delete. После удаления адрес перестанет отвечать.

Перевыпуск ключа OpenRouter закрывает проблему тоже: старый ключ в проекте перестанет работать. Только не забудьте положить новый ключ в воркер: `npx wrangler secret put OPENROUTER_API_KEY --name capsula-claude`, иначе перестанет работать и он.
